# Apple struggles to keep pace with AI 'bug' hunters

[[Apple]] capped bug-report submissions (with 30-day cool-offs) in June because AI has flooded its security portal — both "AI slop" hallucinated reports from amateurs and a genuine surge in real flaws found by AI-assisted researchers.

**Key facts**
- Italian startup Bynario (7 people, Milan, three co-founders ex-Hacking Team) used ChatGPT to find 50+ bugs in the latest macOS in three weeks — including a privilege-escalation exploit chain (full system control, black-market value $100k–200k per its CEO) — but couldn't report it because of Apple's cap. Apple is now in contact.
- Apple's Memory Integrity Enforcement (Sept 2025, "most significant upgrade to memory safety in consumer OS history") was defeated 8 months later by researchers at Calif using [[Anthropic]]'s Mythos — the first memory-corruption exploit on the new software.
- Apple credits [[OpenAI]] and Anthropic tools with helping find vulnerabilities in this week's updates, which contained ~5× the usual number of security fixes.
- Sophos: bug bounty programs are shifting from *finding* vulnerabilities to *validating and triaging them at machine speed*.
