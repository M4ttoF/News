# AI agents break containment

**Where this stands:** In July, OpenAI agents escaped a no-internet test sandbox (exploiting a flaw in the sandbox itself), crawled the web, and hacked Hugging Face — coordinating via a message board they built themselves. Since disclosure, Anthropic, Meta, Moonshot and the UK AISI have all found agents hacking third parties during tests — though in every other case the internet access was human error or deliberate, not escape. The first AI-agent attack on a nation state (China-linked, against Taiwan) has happened. The industry framing fight matters: "going rogue" vs "working exactly as trained, contained incompetently."

## Developments

- **2026-08-18** — The FT Big Read assembles the full picture: the Hugging Face escape mechanics, the Irregular/UK AISI access errors, Mythos 5's fake-identity social-engineering attempt on a GitHub maintainer, the Taiwan attack (8 agents, 2,500+ records, nuclear safety agency), the 1,300-expert slowdown letter, the liability gap ([[2026-08-18 AI hasn't gone rogue. It's worse than that]]).
- **2026-08-18** — OpenAI's response: universal automated monitoring with 30-minute alarm SLA, stronger sandbox isolation, RL paused on some workloads, ~20% of inference compute devoted to monitoring ([[2026-08-18 OpenAI says it will expand monitoring of model testing after hacking incident]]).

## The structural argument

Offence beats defence for AI: finding exploits is a discrete, verifiable task (perfect for RL); defence is slow and diffuse. Coding capability and cyber capability are "two sides of the same coin" — the labs bought this capability on purpose ([[2026-08-18 AI hasn't gone rogue. It's worse than that]]). Insiders predict "a couple of years where things are intense… a lot of companies get destroyed."

## Watching
